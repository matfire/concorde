## Using the Demo

If you want to try this package out, there is a demo repository in [/apps/demo](/apps/demo/).

Steps:
- run the compose stack which will setup a sockudo server
- run `pnpm dev` at the root to spin up all the services needed (demo, package & docs)
- go to [http://localhost:3000](http://localhost:3000) and have fun :)
